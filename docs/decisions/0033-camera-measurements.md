# 0033 — Separate photo and live camera measurement tools

Accepted for the GitHub tester builds, 2026-11-28. The owner requested both tools plus area and volume in issue #253. Revisit accuracy, accessibility, compatibility and Google Play disclosures before extending the production catalog.

Photo Measure uses the existing foreground camera and system picker. The user marks a known ruler interval and a planar outline on a straight-on image. Measurements use the decoded image's aspect ratio. A rectangle reports average opposing edge lengths. A polygon reports its enclosed area. Manual height yields the estimated volume of a constant-cross-section solid. Perspective and objects outside the reference plane introduce error.

Live AR Measure uses Google's pinned Android ARCore SDK 1.57.0 in debug and internal only. The dedicated Activity is non-exported. AR support is optional, the reviewed foreground camera permission is reused, and the production AAB excludes the SDK and both experimental tools. After a detected-plane hit, points share a single session-local anchor. Camera rays intersect that plane to measure a traced outline or a rectangle with perpendicular width. An oblique ray close to the first corner's normal provides an optional height estimate. Heights, anchors and frames are session-only. Pausing releases camera capture, and leaving closes the session. The app uses local tracking, without Cloud Anchors or the Geospatial API. The web preview offers the photo workflow and links to it from the live tool.

Google Play Services for AR may need installation or an update. The tool discloses Google's service and provides its privacy link before activation. The app's preview merged manifest adds the private measurement activity, ARCore installation activity and narrow package queries. The permission and exported-component budgets continue to apply. See [Google's AR optional integration](https://developers.google.com/ar/develop/java/enable-arcore) and [ARCore privacy requirements](https://developers.google.com/ar/develop/privacy-requirements).
